Features

What it does

Per-process routing, node management, and real-time traffic monitoring in one native Windows client: import nodes from links or Clash YAML, route each running process to Proxy, Direct, or Block, and watch live traffic charts on a local HTTP/SOCKS5 listener. Everything stays 100% local — no telemetry, no cloud, and credentials at rest are DPAPI-encrypted. A personal learning project by Akiro, released for learning and technical communication only.

🌐

Node management

Import nodes from links (vless://, vmess://, ss://, trojan://, hysteria2://, tuic://) or Clash YAML configs, or from subscription URLs with optional auto-update — plus concurrent ping tests, search, and editing.

🔀

Per-process routing

Route each running process to Proxy, Direct, or Block with case-insensitive matching (e.g. QQ.exe); rules persist across restarts.

⚙️

Proxy engine

A local HTTP/SOCKS5 listener (default port 3333, auto-migrates on conflict) with Global / Rule / Direct Only / Process Only routing modes and a real-time traffic chart.

🔒

100% local privacy

No telemetry, no cloud. Credentials at rest are DPAPI-encrypted (Windows CurrentUser scope), the engine config lives in temp only while the proxy runs, and registry proxy settings are never touched.

🛡️

Reliability

Single-instance guard; engine lifecycle tied to the app — exiting always kills xray.exe and startup cleans up engines orphaned by a previous crash. Toggle debounce and window size/position persistence included.

🔄

Subscriptions & diagnostics

Subscription feeds auto-update on a configurable interval, replacing stale nodes while manual nodes are never touched. Scheduled latency re-tests, config backup/restore with validation, and a log viewer pairing app logs with live engine output.

🎨

Polish

System/Dark/Light themes, close-to-tray with quick switch, keyboard focus rings on all custom-styled controls, context menus on node cards, and empty-state hints.

Quick Start

Quick start

  1. Import nodes — Nodes page → Import → paste a link, Clash config, or subscription URL.
  2. Start the proxy — click the switch on the top status bar.
  3. Route processes — Processes page → choose Proxy, Direct, or Block for each process.
shell — build & run
# fetch the xray engine assets (xray.exe, wintun.dll, geoip.dat, geosite.dat)
powershell -ExecutionPolicy Bypass -File tools/fetch-assets.ps1

# build (x64)
dotnet build Akiroute/Akiroute.csproj -p:Platform=x64

# run
./Akiroute/bin/x64/Debug/net10.0-windows10.0.19041.0/Akiroute.exe

项目简介

一个原生 Windows 客户端集进程级分流、节点管理与实时流量监控于一体：从链接或 Clash YAML 导入节点，为每个运行中的进程选择代理/直连/阻止，并在本地 HTTP/SOCKS5 监听端口上查看实时流量图表。所有数据 100% 本地——无遥测、无云端，静态存储的凭据经 DPAPI 加密。这是 Akiro 的个人学习项目，仅供学习与技术交流使用。

🌐

节点管理

从链接（vless://、vmess://、ss://、trojan://、hysteria2://、tuic://）或 Clash YAML 配置导入节点，也可从订阅链接导入（可选自动更新）——并支持并发延迟测试（ping）、搜索与编辑。

🔀

进程级路由

将每个运行中的进程路由到代理/直连/阻止，进程匹配不区分大小写（例如 QQ.exe）；规则在重启后依然保留。

⚙️

代理引擎

本地 HTTP/SOCKS5 监听端口（默认 3333，冲突时自动迁移），路由模式：全局 / 规则 / 仅直连 / 仅进程，并配实时流量图表。

🔒

100% 本地隐私

无遥测、无云端。静态存储的节点凭据使用 DPAPI 加密（Windows CurrentUser 范围）；引擎配置仅在代理运行期间存在于临时目录；绝不改动 Windows 注册表中的代理设置。

🛡️

可靠性

单实例保护；引擎生命周期与应用绑定——退出始终会结束 xray.exe，启动时清理上次崩溃遗留的引擎进程。另含开关防抖与窗口大小/位置跨重启保留。

🔄

订阅与诊断

订阅源按可配置间隔自动更新，过期节点被替换，手动导入的节点不受影响。可选的定时自动测速、带校验的配置备份/恢复，以及应用日志与引擎实时输出并排显示的日志查看页。

🎨

体验细节

System/深色/浅色主题、关闭时最小化到托盘并可快速切换、所有自绘控件带键盘焦点框、节点卡片右键菜单，以及空状态提示。
